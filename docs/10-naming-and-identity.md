# 10 · 命名与视觉身份

## 1. 为什么叫 Iris / 虹使

**Iris** 是希腊神话中的彩虹女神，也是众神与人间的**信使**。她沿着彩虹桥穿梭三界，传递消息、引渡灵魂、宣告神谕。

这个名字与项目核心高度重合：

| 神话意象 | 产品对应 |
|---|---|
| 彩虹桥 | 你与数字世界之间的连接通道 |
| 信使 | AI 助手替你收发指令、整理信息、递交请求 |
| 彩虹七色 | 生活多面：求职、出行、财务、文档、琐事 |
| 女神轻盈迅捷 | 对话响应快、审批不打扰、动画柔和 |

中文名 **虹使** = "彩虹信使"，两个字：一个说颜色（明亮、多面），一个说身份（替你行事）。

> 相比之前临时代号 Weave/织，Iris 更响亮、更完整、更有画面，也更适合作为个人产品的名字被喊出来。

## 2. Logo 设计方向

### 2.1 核心符号：彩虹圆环

推荐主 Logo 是一个**封闭的彩虹圆环**（或稍扁的椭圆环）：

- **圆环**象征连接、完整、循环——对话是环状的（你说 → 它做 → 反馈 → 继续）。
- **彩虹渐变**象征生活多面，也暗含"把零散光谱聚成一束白光"的意象：Iris 把你的杂乱琐事整理成清晰指令。
- 圆环可以稍微缺一个小口，像未完成的对话，暗示"持续进行"。

### 2.2 变体与使用场景

| 场景 | 形式 | 说明 |
|---|---|---|
| App 图标 / 任务栏 | 实心彩虹圆环，中心留白或放字母 "I" | 小尺寸下仍清晰 |
| 启动页 / 关于页 | 圆环 + 文字 "Iris · 虹使" | 完整品牌组合 |
| 加载动画 | 圆环微旋转 + 光谱流动 | 呼应"信使穿梭" |
| 徽章 / 社交封面 | 圆环 + 彩虹射线 | 更装饰性的版本 |
| 单色场景 | 单线圆环 + 灰阶 | 打印 / 水印 |

### 2.3 色彩系统

彩虹当然要明亮，但作为常驻桌面的个人助手，不能太艳：

- **主光谱**：红 `#FF6B6B` → 橙 `#FF9F43` → 黄 `#FDCB6E` → 绿 `#6DD5A7` → 青 `#4ECDC4` → 蓝 `#6C9CF2` → 紫 `#A29BFE`
- **背景色**：极浅灰 `#FAFAFA` 或暖白 `#F7F6F3`（类似 Notion 的纸质感）
- **文字主色**：深灰 `#1F1F1F`，不使用纯黑
- **强调色**：从光谱中取一色随场景变化——例如求职用蓝，出行用绿，财务用紫

色彩原则：**像雨后彩虹，不是霓虹灯**。饱和度高但明度也高，看起来清新、透气。

### 2.4 字体建议

- **英文**：Inter / Geist / Plus Jakarta Sans —— 现代、清晰、开源
- **中文**：思源黑体 / 霞鹜文楷（如果走温和路线）/ 得意黑（如果走科技路线）
- 标题可用稍微有特点的字体，正文必须极致易读

### 2.5 首个 Logo 草图描述

如果你要手绘第一版，可以按这个描述：

```
一个粗细适中的圆环，环内从左上到右下有一道柔和彩虹渐变。
圆环中心留白，或放一个极简的小写字母 "i"（圆点做成小光点）。
整体略微倾斜 15°，像一枚正在传递的信封封蜡。
```

## 3. 品牌关键词

用三个词概括 Iris：

1. **连接**（Connect）—— 人与信息、人与网页、人与日常
2. **清晰**（Clear）—— 复杂琐事被整理得井井有条
3. **轻盈**（Light）—— 不厚重、不打扰、像一道光掠过

---

## 4. 命名决策记录

- **曾用名**：Weave/织
- **最终名**：Iris/虹使
- **决策时间**：2026-07-24
- **决策理由**：
  1. Weave 意境好但偏常见，且 "织" 作为动词在项目名和产品名之间容易混淆；
  2. Iris 是完整单词、两音节顺口、有神话画面，Logo 易设计；
  3. "彩虹女神 + 信使" 的意象准确对应"知根知底的个人助手"定位。
