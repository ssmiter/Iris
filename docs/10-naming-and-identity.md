# 10 · 命名与视觉身份

## 1. 为什么叫 Iris

**Iris** 是希腊神话中的彩虹女神，也是众神与人间的**信使**。她沿着彩虹桥穿梭三界，传递消息、引渡灵魂、宣告神谕。

这个名字与项目核心高度重合：

| 神话意象 | 产品对应 |
|---|---|
| 彩虹桥 | 你与数字世界之间的连接通道 |
| 信使 | AI 助手替你收发指令、整理信息、递交请求 |
| 彩虹七色 | 生活多面：求职、出行、财务、文档、琐事 |
| 女神轻盈迅捷 | 对话响应快、审批不打扰、动画柔和 |

“虹使”保留为中文命名故事中的解释：彩虹的信使、连接不同数字世界的人。它不再与产品名机械地固定拼成 `Iris · 虹使`，也不作为 Iris 自称用户助手时的第三人称称谓。

> 相比之前临时代号 Weave/织，Iris 更响亮、更完整、更有画面，也更适合作为个人产品的名字被喊出来。

### 1.1 界面怎样称呼它

- App 标题、空状态和任务栏名称统一使用 **Iris**；
- About/README 可以解释 Iris 与“虹使”的关系；
- 中文文案直接说“交给 Iris”“Iris 正在处理”，不说“交给知根知底的虹使”；
- Iris 不频繁讲述自己的神话身份。品牌故事负责留下记忆，产品文案负责把事情说清楚。

默认空状态语气：

```text
Iris
想先处理哪件事？
文件、网页，或一个还没理清的念头，都可以从这里开始。
```

## 2. Logo 设计方向

### 2.1 核心符号：彩虹圆环

推荐主 Logo 是一个**封闭的彩虹圆环**（或稍扁的椭圆环）：

- **圆环**象征连接、完整、循环——对话是环状的（你说 → 它做 → 反馈 → 继续）。
- **彩虹渐变**象征生活多面，也暗含"把零散光谱聚成一束白光"的意象：Iris 把你的杂乱琐事整理成清晰指令。
- 圆环可以稍微缺一个小口，像未完成的对话，暗示"持续进行"。

### 2.2 变体与使用场景

| 场景 | 形式 | 说明 |
|---|---|---|
| App 图标 / 任务栏 | 实心彩虹圆环，中心留白或放字母 "I" | 小尺寸下仍清晰 |
| 启动页 / 关于页 | 圆环 + 文字 "Iris" | 完整品牌组合 |
| 加载动画 | 圆环微旋转 + 光谱流动 | 呼应"信使穿梭" |
| 徽章 / 社交封面 | 圆环 + 彩虹射线 | 更装饰性的版本 |
| 单色场景 | 单线圆环 + 灰阶 | 打印 / 水印 |

### 2.3 色彩系统

彩虹是身份签名，不是界面的常驻填充色。长时间使用的个人助手需要安静的中性表面、稳定的状态色，以及一个可识别的 Iris 主色：

- **Iris 主色**：violet-blue `#575FC7`，用于主动作、焦点和当前选中；
- **品牌光谱**：coral `#E98178` → gold `#D8A542` → mint `#62B891` → sky `#6FA7D8` → iris `#787EDB`；
- **亮色背景**：暖灰 `#F7F7F4`，内容面 `#FCFCFA / #FFFFFF`；
- **文字主色**：`#1F211E`，不使用纯黑；
- **状态色**：成功、警告、危险、信息使用固定语义色，不随生活域变化；
- **暗色主题**：独立设计表面与文字层级，不对亮色简单反相。

色彩原则：**像雨后折射，不是霓虹灯**。单屏最多一个持续可见的光谱焦点；普通按钮、卡片和领域导航不能同时争用彩虹。

### 2.4 字体建议

- **英文**：Inter / Geist / Plus Jakarta Sans —— 现代、清晰、开源
- **中文**：思源黑体 / 霞鹜文楷（如果走温和路线）/ 得意黑（如果走科技路线）
- 标题可用稍微有特点的字体，正文必须极致易读

### 2.5 首个 Logo 草图描述

如果你要手绘第一版，可以按这个描述：

```
一个粗细适中的圆环，环内从左上到右下有一道柔和彩虹渐变。
圆环中心留白，或放一个极简的小写字母 "i"（圆点做成小光点）。
整体略微倾斜 15°，像一枚正在传递的信封封蜡。
```

## 3. 品牌关键词

用四个词概括 Iris：

1. **连接**（Connect）—— 人与信息、人与网页、人与日常
2. **清晰**（Clear）—— 复杂琐事被整理得井井有条
3. **轻盈**（Light）—— 不厚重、不打扰、像一道光掠过
4. **可靠**（Reliable）—— 每个动作有边界，每个结果有来处

产品文案不是神话旁白。默认语气是安静、直接、温和而精确：先说结果，再说影响和下一步；少用“为你赋能”“知根知底的虹使”等自我描述。

## 4. 命名决策记录

- **曾用名**：Weave/织
- **产品名**：Iris
- **中文命名故事**：虹使（不作为界面固定并列名）
- **决策时间**：2026-07-24
- **决策理由**：
  1. Weave 意境好但偏常见，且 "织" 作为动词在项目名和产品名之间容易混淆；
  2. Iris 是完整单词、两音节顺口、有神话画面，Logo 易设计；
  3. “彩虹女神 + 信使”的意象准确对应连接个人与数字世界的定位；
  4. 界面只使用 Iris，避免中文称谓反复出现时机械、拟人过度。
