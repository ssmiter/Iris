## 2. 跑起来的正确姿势（踩过的坑）

```bash
# 后端（必须带 local profile，否则无模型 provider，发消息"没反应"）
cd backend && ./mvnw spring-boot:run -Dspring-boot.run.profiles=local

# 前端
cd frontend && npm run dev        # :15173，/api 代理 :15001

# WebBridge daemon（浏览器自动化，按需）
cd webbridge-daemon && npm start  # :19223
```

- **API key 在 gitignored 的 `backend/application-local.yml`**（工作目录下的
  那份，不是 `src/main/resources/` 里带占位符的模板）。`local` profile
  指向 DeepSeek（openai-compatible），key 从该文件读取。
- 杀后端残留进程：`TaskStop` 只杀 mvnw 壳，fork 出的 Java 进程会留下占
  15001——`netstat -ano | grep :15001` 找 PID 后 `taskkill //PID <pid> //F`。
- 上次启动恢复时出现一次 `SQLITE_BUSY_SNAPSHOT`（标题更新与恢复写入并发），
  属已知待办（见 §5），不是新回归。
