# 06 · 对话内核（Agent Loop）

> 对话循环是体验的心脏：轮次怎么切、补充怎么进、上下文怎么压缩、分支怎么长。
> 前端默认执行循环，后端是无状态平台（架构决策 D1）。

## 1. 轮次模型（Turn = N × Round）

- **Turn**：从一条用户消息开始，到下一用户消息之前的全部内容。
- **Round**：一轮"思考→工具→再思考"。模型每次返回要么给答案（turn 收敛），要么给工具调用（开下一 round）。
- 渲染数据：**renderNodes**——thinking / tool / answer / attention / artifact 五类节点组成过程流；rounds 快照记录每轮节点归属与统计（思考时长/工具数/总耗时）。

```
Turn
├── Round 1: thinking → tool(read) → tool(search)
├── Round 2: thinking → tool(write) [审批]
└── answer（最终回答）
```

## 2. 补充注入（Supplement）——不打断的中途指令

用户运行中再输入，不是排队也不是打断：

1. 补充消息打上 `isSupplement` 标记入历史；
2. 在**下一个 loop 边界**（模型即将发起下一次调用前）作为用户消息注入上下文；
3. 视觉：composer 上方 chip 脉冲→淡出，不占气泡层级（模型接续回应就是反馈）；
4. 若 turn 在边界前结束：补充自动作为新 turn 发出；
5. **手动停止 = 完全停止**：未注入的补充转为排队 chip（不自动发），无自动续跑——杜绝"停不下来"的死循环。

竞态规则：注入只发生在 loop 边界的一个点，注入后清空 pending；停止信号同样只在边界生效。单点决策，无并发窗口。

## 3. 压缩线（Compact Lines）——历史不动，视野滑动

上下文接近上限时压缩，但**历史一个字都不删**：

- 压缩 = 生成摘要 + 画一条线：`{ id, cutoffTs, summary, coveredCount, trigger(manual/auto) }`；
- 线前的记录保持原样；线后的新对话，上下文装配 = 摘要 + 线后原文；
- 压缩进度有细轨道进度条，完成"✓ 已压缩"短暂停留后淡出；
- 手动 `/compact` 与超长自动压缩同一语义。

## 4. 分支多叉树（Branch Tree）

任何用户消息可编辑重发，长出分叉：

```
                      ┌─ 变体1（原始提问）─ 后续...
锚点用户消息 ─────────┼─ 变体2（改问法A）─ 后续...
                      └─ 变体3（改问法B）─ 后续...
```

- **BranchAnchor**：`{ anchorId, anchorText, variants[], active }`；变体保存完整尾部快照（含 renderNodes/工具结构——不裁剪，切换无损）；
- 同一锚点最多 5 个变体（快照体积约束）；
- 气泡下 ‹ 2/5 › 切换；切换伴随工作区检查点回滚（文件状态跟随分支）；
- **key 恒为首个变体的锚点消息 id**——从非首变体上再编辑时按变体 anchorMsgId 找回真锚点（否则会长出"永远只有 2 个分支"的伪锚点）。

## 5. 压缩 × 分支的统一：位置语义

两者交汇处是最容易出 bug 的地方，规则只有一条：

> **在哪个位置分叉，就用那个位置该用的上下文。**

- 分叉点（锚点时间戳）在压缩线后 → 该轮压缩摘要有效；
- 分叉点在线前 → 落回更早的线（或第 0 条线 = 无压缩，全原始上下文）；
- 多轮压缩 = 多条线，选"切点早于最早分叉点"的最新一条；
- 判定函数唯一：`selectActiveBoundary(messages, boundaries, branches)`，装配、分隔线渲染、token 估算三处共用。

## 6. 系统提示组装

分层注入（优先级从高到低）：

1. identity（你是谁/行为准则）
2. **已加载域声明**：可见域 + 各域工具数 + 发现流程五步法 + 禁令（docs/03 §6）
3. 工作区说明（路径围栏、产物机制）
4. 当前上下文状态（压缩摘要、激活的项目/技能）
5. 用户记忆（`/remember` 关键词检索注入）

## 7. 持久化

| 数据 | 位置 | 说明 |
|---|---|---|
| 消息 + renderNodes | 后端 SQLite（或 IndexedDB） | 结构完整，含工具结果 |
| 分支记录 | IndexedDB（`branches-<convId>`） | 600ms 写防抖 |
| 压缩边界 | IndexedDB（`compacts-<convId>`） | 同上 |
| 检查点 | `.weave/checkpoints/` | 文件系统，按锚点消息 id |

防抖写入 + 删会话时级联清理；旧 localStorage 数据首次加载自动迁移。

## 8. 防死循环红线

- 手动停止不触发任何自动发送；
- 自动压缩失败后退避，不立即重试；
- 工具错误回注模型时带"不要重复同样调用"的提示，同类错误 3 次循环熔断；
- 审批超时 = rejected，不静默重发。
