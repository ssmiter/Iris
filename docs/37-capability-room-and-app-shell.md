## 1. 空间模型：从 Modal 到覆盖式全屏房间

用户 2026-08-20 定稿：**覆盖层而非替换层**——对话页始终在下层保持
挂载与可见，能力层尽量占满屏幕，点旁边空白即返回，无切换认知负担；
不用滑入、不用转场大动画。

- 能力中心从 Modal 升级为**近全屏覆盖层**：`position:fixed` 居中，
  四周留 24-40px 边缘（ inset 约 `clamp(12px, 3vw, 40px)` ），圆角
  14-18px + 大软阴影（`--pop` 级），下层的对话在边缘保持可见。
- 下层对话**只加一层极淡的压暗**（canvas 40-50% 透明遮罩，随能力层
  一次性淡入），不缩放不模糊——用户看得见"对话还在那儿"。
- **点遮罩/边缘空白 = 返回**；Esc = 返回；头部"← 返回" = 返回。
  三条回家路径等价，零学习成本。
- 动效上限：覆盖层与遮罩各一次 opacity 淡入（≤duration-fast），
  无位移、无缩放、无滑入。
- 对话层只遮罩不卸载（SSE/滚动位置/流式状态全部原位保留）。
- 实现走 viewStateStore 视图态（不引入前端路由）；同一覆盖机制日后
  可承载设置房。

## 2. 能力房内部：Explorer 式管理

### 2.1 布局（比 chatgpt 设置页更大更清晰）

```
┌ sticky 头：← 返回 · 能力 · [搜索] ─────────────┐
├────────────┬──────────────────────────────────┤
│ 目录树列    │ 内容区（当前目录）                 │
│ （可折叠）   │ 大图标/列表两种视图               │
│            │ 右键菜单 / 多选 / 拖放            │
├────────────┴──────────────────────────────────┤
│ 状态行：N 项 · 选中 M 项 · 目录统计             │
└────────────────────────────────────────────────┘
```

- 字号规格对齐资源管理器可读性：内容区对象名 14px/500、辅助行 12.5px、
  组标题 12px letterspacing muted（原型 `.side-g`/`.group-t` 同款）。
- **信息减重**：卡片不再堆徽标——kind 由图标砖表达、风险只在详情与
  destructive/elevated 时出边缘色、来源收成详情一行；列表态每行 =
  图标砖 + 名称 + 一句话 + 状态点文字。
- 目录统计沿用 `_directory.yml` 三口径，放状态行而非每目录一堆数字。

### 2.2 右键菜单（按真相源分档，docs/36 方向落地）

新建 `ui/ContextMenu.tsx`（自绘轻量：复用 PermissionModeSelect 的菜单语言，
不引新依赖；键盘可达、Esc 关闭、点外关闭、暗色胶囊）。菜单内容按对象
真相源分档：

| 真相源 | 菜单项 | 语义 |
|---|---|---|
| 文件真相（process/template/skill/knowledge） | 打开编辑 / 剪切 / 复制 / 粘贴 / 重命名 / 删除 / 在文件夹中显示 / 复制路径 | 剪切粘贴 = 真实移动文件；重命名 = 真实改文件名（manifest 同步）；删除先确认 Modal |
| DB 真相（kernel_skill/mcp 手工/schedule） | 打开编辑 / 重命名（语义允许处）/ 删除（确认）/ 复制路径 | 编辑进现有编辑器 |
| 内核工具 | 详情 / 复制调用名 / 复制路径 | 包名即路径不可动，菜单诚实收敛 |

- **多选**：Ctrl/Shift 点选 + 空白处框选（资源管理器肌肉记忆）；
  多选菜单只剩可批量执行的动作（剪切/删除）。
- **拖放**：对象拖到目录树节点 = 移动（与剪切粘贴同一后端动作）；
  只允许文件真相对象、只提示合法落点。
- 剪切板语义照 Windows：剪切后源项半透明待粘贴；跨目录粘贴 = 移动；
  同名冲突拒绝并提示；复制粘贴 = 副本（"xxx 副本"后缀）。

### 2.3 后端文件操作写接口（新增）

挂在 `/api/v1/capability-admin/files`（管理面，与模型原语完全分离）：

- `POST /move`（source→target 目录）、`POST /rename`、`POST /copy`、
  `POST /delete`，全部：
  - **拓展根围栏 fail-close**：源与目标都必须解析在已登记拓展根内，
    越界一律拒绝（与不变量 4 同构）；
  - 内核目录/DB 真相路径直接 422；
  - 操作成功后触发该根热重扫（复用现有重扫管线），目录树投影自动跟随；
  - 冲突不覆盖，返回结构化 409。
- 操作主体是**用户本人在界面上直接操作**，不经模型——不破"写操作必
  审批"（那是对模型工具的不变量）；删除仍走前端确认 Modal。
- 管理页第一次有写能力：审计留痕（log + 操作返回投影），不做回收站
  （克制：删除有确认，文件仍在 git/文件系统可恢复时不造第二机制）。

### 2.4 策展层（真相树之上的自由组合）

"可拖动自由组合"的组织欲由策展层承接，不动真相路径：

- 目录树顶部一个「收藏」区：任意能力可钉入（右键菜单"钉到收藏"），
  收藏区内自由排序（拖放仅改展示顺序）；
- 持久化 SQLite 单表（capability_pin：path + ordinal），重启保留；
- **不做**自定义嵌套文件夹（第一期克制：收藏平铺已覆盖 80% 诉求，
  嵌套分组留待实际手感再评）。

## 3. 干净度配方沉淀（第二波正在执行的部分在此定标）

从应用壳原型与 chatgpt 照片提炼、已派给第二波的硬性规格：

- 字体：`14px/1.6` 基底、`-webkit-font-smoothing: antialiased`、
  强调字重 550-600 克制使用、组标题 11-12px + letter-spacing .12em；
  caption 最低可用字号 12px（中文 ≤11.5px 发虚）。
- 表面：hairline 用极淡色（`--hair` 系）、阴影两层（近距小 + 远距软）、
  卡片圆角 14px、行间分隔线左缩进对齐图标后（原型 `left:47px` 手法）。
- 颜色纪律：界面几乎无色——墨色阶 + 纸面；颜色只服务强调色与状态
  语义（小点 + 文字永远成对）。
- toast：深色胶囊、顶部居中、单次淡入（原型 `.toast` 同款）。

## 4. 不做（防反悔）

- 不做"发现间/货架/市场"（个人版阶段，docs/34 已裁决打包分发不做）；
  v12 的引导触点与情境推荐卡同样不做（无可推荐的货架）。
- 不做微光飞入/接线动画等叙事动效（视觉克制不变量）。
- 不做自定义嵌套分组文件夹（第一期）；不做回收站；不做能力级审批策略
  编辑（规则化权限是 docs/35 §5 独立排队项，届时再评入口）。
- 内核工具的移动/重命名永不做（包名即路径，第一原则）。
- 前端不引新依赖（ContextMenu 自绘；Radix 仅 dialog 现状保持）。

## 5. 验收标准

1. 能力中心以近全屏覆盖层打开（四周留边、下层对话边缘可见且仅压暗
   不卸载），无位移/缩放/滑入转场（最多一次 opacity 淡入 ≤duration-fast）；
   点边缘空白 / Esc / "← 返回"三条路径等价返回，对话状态原位保留；
2. 文件真相对象可右键剪切/粘贴/重命名/删除，操作后热重扫即时反映；
   越界与内核对象被明确拒绝且提示人话；
3. 多选与拖放移动手感与资源管理器一致；冲突拒绝不覆盖；
4. 收藏区可钉选、可排序、重启保留；
5. 字号密度达到"比 chatgpt 设置页更大更清晰"（14px 基底、行规格对齐 §2.1）；
6. 全部动画 ≤.5s 且为单次转场；无轮询；token 纪律零违规。
