# 09 · 路线图

## M0 · 骨架可跑（1-2 周）
- [ ] backend：Spring Boot 工程 + `/api/chat/proxy` SSE（接一家 OpenAI 兼容模型）
- [ ] frontend：Vite React 工程 + 最小对话页（发消息、流式显示）
- [ ] SQLite 历史（会话/消息两表）

## M1 · 对话内核（2-3 周）

- 验收：一次长对话里完成补充、分支、压缩、回分支继续，全部无损

## M2 · 工具平台（2-3 周）

- [ ] 首批生活域工具（≥30 个）：notes / express / finance / calendar / files
